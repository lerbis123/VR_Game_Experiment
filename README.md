# VR Games

A WebXR VR sandbox that runs in your headset's browser. Your PC hosts it on your local network (LAN), and your headset connects over Wi-Fi. There's nothing to install on the headset.

## Run it

On your PC (needs [Node.js](https://nodejs.org)):

```bash
npm install
npm run dev
```

## Play it

1. Put your headset (e.g. Meta Quest 3) on the same Wi-Fi as your PC.
2. Open the headset's browser and go to the **Network** address the server prints, e.g. `https://192.168.1.173:5173`.
3. Accept the security warning (the certificate is self-signed), then tap **Enter VR**.

In VR, click the **left thumbstick** to open the control panel and switch features on.
